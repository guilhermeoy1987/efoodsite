# efood - Delivery de Gastronomia

O **efood** é uma plataforma de delivery de restaurantes selecionados, desenvolvida em React com TypeScript. O projeto foca em uma experiência de usuário fluida, permitindo a visualização de cardápios, detalhes de pratos e um sistema de carrinho funcional.

## 🚀 Tecnologias Utilizadas

*   **React** (com Hooks e Functional Components)
*   **TypeScript** (para tipagem estática e segurança do código)
*   **Styled Components** (estilização baseada em componentes)
*   **Redux Toolkit** (gerenciamento de estado global para o carrinho)
*   **React Router Dom** (navegação entre a home e a página de perfil do restaurante)

## 🛠️ O que foi desenvolvido

Nesta etapa do projeto, foram implementadas as seguintes funcionalidades:
*   **Navegação Dinâmica:** Implementação do roteamento para transição entre a listagem de restaurantes e a página interna.
*   **Header de Perfil:** Criação de um cabeçalho específico para a página do restaurante, exibindo o link de retorno e o estado atual do carrinho.
*   **Gerenciamento de Estado:** Integração com Redux para controlar a abertura/fechamento do carrinho e contagem de itens.
*   **Correções de Tipagem:** Refatoração de componentes para garantir que as propriedades e estados sigam as interfaces do TypeScript.
